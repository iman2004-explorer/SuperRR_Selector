# Source data

Place the authorized source data CSVs in this directory before running the model:

- `ball_by_ball.csv`
- `matches.csv`
- `competitions.csv`
- `teams.csv`
- `competition_team_player_mapping.csv`
- `playing_eleven.csv`

The source data pack is intentionally not distributed with this repository. Ensure you have permission to use and redistribute any data before publishing it.
